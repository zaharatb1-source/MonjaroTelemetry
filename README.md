# Monjaro 3D Telemetry (Verified Build)

Полноценное приложение 3D-телеметрии для Geely Monjaro (1-й рестайлинг, GMC).

## Команда быстрой распаковки и сборки в GitHub Codespaces
1. Загрузи `MonjaroTelemetry_3D_Verified.zip` в корень Codespaces.
2. Выполни в терминале:
```bash
rm -rf app .github settings.gradle build.gradle gradle.properties README.md && unzip -o MonjaroTelemetry_3D_Verified.zip && rm -f MonjaroTelemetry_3D_Verified.zip && git add . && git commit -m "Build verified 3D Monjaro Telemetry" && git push
```

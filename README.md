# Monjaro Telemetry (Need For Speed Style)

Кастомное приложение телеметрии для Geely Monjaro (1-й рестайлинг, прошивка GMC) с выводом на основной или пассажирский экран и плавающим мини-виджетом поверх навигатора.

## Возможности
- **Анимация автомобиля в стиле Need For Speed:** динамическая перспектива дороги, реакция на скорость, крен кузова при повороте руля, подсветка днища, стоп-сигналы при торможении и аэродинамические потоки в режиме Sport.
- **Адаптация цвета под режим движения:** автоматическая смена неоновой подсветки (Comfort — голубой, Sport — красный, Eco — зелёный, Offroad — янтарный).
- **Полный набор датчиков с цветовой индикацией (холодный / норма / перегрев):**
  - Температура ОЖ двигателя (°C)
  - Температура масла АКПП Aisin (°C)
  - Температура масла двигателя (°C)
  - Давление наддува турбины (Bar) и обороты (RPM)
  - Напряжение бортовой сети (V)
  - Температура воздуха на впуске и на улице (°C)
  - Процент нажатия педали газа и тормоза (%)
  - Угол поворота руля (°)
  - Давление (Bar) и температура (°C) в каждом колесе (TPMS)
  - Остаток топлива (%)
- **Гибкая настройка:** кнопка «Датчики ⚙» позволяет в один клик включать и отключать любые карточки.
- **Демо-режим:** кнопка «Демо» для проверки анимаций и всех датчиков на заглушенной машине.
- **Плавающий мини-виджет:** компактная перетаскиваемая плашка поверх Яндекс Навигатора (`ОЖ | АКПП | Масло | Наддув | Вольтаж`).

## Сборка APK без ПК через GitHub Actions
1. Создай новый репозиторий на GitHub (например, `MonjaroTelemetry`).
2. Загрузи все файлы из этого архива в корень репозитория.
3. Перейди во вкладку **Actions** → выбери **Build Monjaro Telemetry APK** → нажми **Run workflow** (или сборка запустится сама после загрузки файлов).
4. Через 1–2 минуты скачай готовый `MonjaroTelemetry-debug.zip` в разделе **Artifacts** внизу страницы сборки, распакуй `app-debug.apk` и установи на ГУ.
